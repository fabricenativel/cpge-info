\subQuestion{\mintinline{ocaml}{let perimetre = 4 *. 2.5;;}}

\subQuestion{Écrire une fonction d'ordre supérieur \mintinline{ocaml}{dichotomie} prenant en argument une fonction continue $f$, deux réels $a$ et $b$ vérifiant $f(a) \cdot f(b) \le 0$ et une tolérance $\varepsilon > 0$, et renvoyant une approximation du zéro de $f$ sur $[a, b]$. \begin{Exercise}[title={Les listes et la récursion structurelle}]

\subQuestion{\mintinline{ocaml}{longueur : 'a list -> int} qui calcule la longueur d'une liste.}
\subQuestion{\mintinline{ocaml}{somme : int list -> int} qui calcule la somme des éléments d'une liste d'entiers (la somme de la liste vide valant 0).}
\subQuestion{\mintinline{ocaml}{appartient : 'a -> 'a list -> bool} qui teste si un élément est présent dans une liste.}
\subQuestion{\mintinline{ocaml}{n_ieme : int -> 'a list -> 'a} qui renvoie l'élément situé à l'indice $n$ d'une liste ($n \ge 0$, le premier élément étant à l'indice 0). Si $n$ est hors limites, on pourra lever une erreur avec \mintinline{ocaml}{failwith "Indice invalide"}.}
\Question{Écrire une fonction récursive \mintinline{ocaml}{intervalle : int -> int -> int list} telle que \mintinline{ocaml}{intervalle a b} renvoie la liste des entiers consécutifs de $a$ à $b$ inclus (ou la liste vide si $a > b$). Par exemple, \mintinline{ocaml}{intervalle 3 7} renvoie \mintinline{ocaml}{[3; 4; 5; 6; 7]}.}
\Question{Inversion d'une liste :}
\subQuestion{Écrire une fonction récursive naïve \mintinline{ocaml}{renverser : 'a list -> 'a list} utilisant l'opérateur de concaténation {\tt @}. Justifier que sa complexité temporelle est quadratique en la taille $n$ de la liste.}
\subQuestion{Pour obtenir une complexité linéaire en temps, écrire une fonction auxiliaire récursive terminale \mintinline{ocaml}{rev_acc : 'a list -> 'a list -> 'a list} utilisant un accumulateur, puis en déduire une fonction \mintinline{ocaml}{renverser_rapide : 'a list -> 'a list}.}
\Question{Écrire une fonction récursive \mintinline{ocaml}{partitionner : ('a -> bool) -> 'a list -> 'a list * 'a list} qui sépare une liste en un couple de deux listes : celle des éléments vérifiant le prédicat, et celle des éléments ne le vérifiant pas.}
\end{Exercise}
