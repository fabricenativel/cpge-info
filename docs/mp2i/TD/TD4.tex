\begin{Exercise}[title = {Convergence d'une suite}]\\
On considère la suite : \\
$\left\{ \begin{array}{ll} u_0=e-1 \\ u_{n+1} = (n+1)\,u_n - 1 \end{array}\right.$ \\
Le but de l'exercice est d'établir que cette suite converge vers 0. \\
On note $$S_n = \displaystyle{\sum_{k=0}^n \frac{1}{k!}}$$ 
On pourra utiliser sans justification le résultat suivant (qui sera démontré en mathématiques) : pour tout $n \in \N^*$ : \mbox{$S_n \leq e \leq S_n + \dfrac{1}{n\,n!}$}

\Question{Montrer que $ e = \displaystyle{\lim_{n \rightarrow +\infty} S_n}$}
\Question{Montrer que pour tout $n\in \N$, $u_n = n!(e-S_n)$}
\Question{En déduire que $(u_n)_{n \in \N}$ converge et donner sa limite.}
\Question{Calculer les premiers termes de cette suite à l'aide de votre calculatrice. Commenter.}
\end{Exercise}

\begin{Exercise}[title={Caractérisation des nombres dyadiques}]\\
Un nombre réel $x \in [0, 1[$ est dit dyadique s'il admet une écriture binaire finie, c'est-à-dire qu'il existe un entier $p \in \N^*$ et des bits $b_1, \dots, b_p \in \{0, 1\}$ tels que :
$$x = \sum_{k=1}^p b_k \, 2^{-k}$$
\Question{Montrer qu'un nombre rationnel $x = \dfrac{a}{b}$ sous forme irréductible ($a, b \in \N^*$, $\mathrm{pgcd}(a, b) = 1$) est dyadique si et seulement si son dénominateur $b$ est une puissance de 2 (c'est-à-dire qu'il existe $k \in \N$ tel que $b = 2^k$).}
\tcor{
$\bullet$ Si $x$ est dyadique, alors :
$$x = \sum_{k=1}^p b_k \, 2^{-k} = \frac{\sum_{k=1}^p b_k 2^{p-k}}{2^p} = \frac{N}{2^p} \quad \text{avec } N \in \N$$
La fraction irréductible $\dfrac{a}{b}$ s'obtient en simplifiant $\dfrac{N}{2^p}$ par $\mathrm{pgcd}(N, 2^p)$. Comme les seuls diviseurs de $2^p$ sont des puissances de 2, le dénominateur $b$ est nécessairement de la forme $2^k$ (avec $k \leqslant p$).\\
$\bullet$ Réciproquement, si $b = 2^k$, alors $x = \dfrac{a}{2^k} = a \times 2^{-k}$. En écrivant la décomposition binaire de l'entier $a$ : $a = \sum_{j=0}^m c_j 2^j$, on obtient :
$$x = \sum_{j=0}^m c_j 2^{j-k}$$
Comme $x \in [0, 1[$, on a $a < 2^k$, donc $m < k$ et les exposants $j-k$ sont tous strictement négatifs. Cela constitue bien une écriture binaire finie, donc $x$ est dyadique.
}
\Question{Parmi les nombres suivants, déterminer ceux qui possèdent une écriture dyadique finie :
$$x_1 = \frac{7}{16} \qquad x_2 = \frac{3}{25} \qquad x_3 = 0{,}1 = \frac{1}{10} \qquad x_4 = \frac{13}{64}$$}
\tcor{
$\bullet$ $x_1 = \dfrac{7}{16} = \dfrac{7}{2^4}$ : le dénominateur est une puissance de 2, l'écriture dyadique est finie ($x_1 = \base{0,0111}{2}$).\\
$\bullet$ $x_2 = \dfrac{3}{25} = \dfrac{3}{5^2}$ : le dénominateur admet 5 comme facteur premier, l'écriture est donc infinie.\\
$\bullet$ $x_3 = \dfrac{1}{10} = \dfrac{1}{2 \times 5}$ : le dénominateur admet 5 comme facteur premier, l'écriture est infinie (périodique : $\base{0,000110011\dots}{2}$).\\
$\bullet$ $x_4 = \dfrac{13}{64} = \dfrac{13}{2^6}$ : le dénominateur est une puissance de 2, l'écriture est finie ($x_4 = \base{0,001101}{2}$).
}
\Question{En déduire pourquoi aucun ordinateur travaillant en base 2 ne peut représenter exactement le nombre $0{,}1$, même en augmentant la taille de la mantisse.}
\tcor{
Puisque $0{,}1 = \frac{1}{10}$ n'est pas un rationnel dyadique, son écriture en base 2 nécessite une infinité de bits. Tout format flottant (qu'il soit codé sur 32 bits, 64 bits ou davantage) ne disposant que d'un nombre fini de bits pour stocker la mantisse, le nombre $0{,}1$ subit obligatoirement un arrondi, ce qui introduit une erreur de représentation intrinsèque.
}
\end{Exercise}

\begin{Exercise}[title={Codage ASCII et bit de parité}]\\
Le standard ASCII d'origine n'utilise que 7 bits par caractère (codes de 0 à 127). Dans les télécommunications, le 8\textsuperscript{e} bit (bit de poids fort) servait historiquement de \textit{bit de parité} pour détecter d'éventuelles erreurs de transmission sur la ligne.\\
Dans un protocole à \textbf{parité paire}, on choisit le bit de poids fort de sorte que le nombre total de bits à 1 dans l'octet soit \textbf{pair}.
\Question{Donner la suite d'octets en hexadécimal représentant la chaîne {\tt "MP2I"} en ASCII standard sur 7 bits (avec le bit de poids fort à 0).}
\tcor{
D'après les codes ASCII :\\
$\bullet$ {\tt 'M'} a pour code décimal $77 = 4 \times 16 + 13 = \base{4D}{16}$.\\
$\bullet$ {\tt 'P'} a pour code décimal $80 = 5 \times 16 + 0 = \base{50}{16}$.\\
$\bullet$ {\tt '2'} a pour code décimal $50 = 3 \times 16 + 2 = \base{32}{16}$.\\
$\bullet$ {\tt 'I'} a pour code décimal $73 = 4 \times 16 + 9 = \base{49}{16}$.\\
La suite d'octets en hexadécimal est donc : {\tt 4D 50 32 49}.
}
\Question{Pour chacun des caractères suivants, donner son code ASCII sur 7 bits en binaire, puis déterminer la valeur de l'octet complet (sur 8 bits) avec bit de parité paire :}
\begin{enumerate}
    \item Le caractère {\tt 'A'} (code décimal 65).
    \item Le caractère {\tt 'C'} (code décimal 67).
\end{enumerate}
\tcor{
\begin{enumerate}
    \item $65 = 64 + 1 = \base{1000001}{2}$. Cette séquence de 7 bits contient 2 bits à 1, ce qui est déjà pair. Le bit de parité (de poids fort) est donc mis à 0. L'octet complet est $\base{01000001}{2}$ ({\tt 0x41}).
    \item $67 = 64 + 2 + 1 = \base{1000011}{2}$. Cette séquence contient 3 bits à 1 (nombre impair). Le bit de parité est donc mis à 1 pour obtenir un total pair (4 bits à 1). L'octet complet est $\base{11000011}{2}$ ({\tt 0xC3}).
\end{enumerate}
}
\Question{Un récepteur reçoit l'octet $\base{11000101}{2}$. Détecte-t-il une erreur de transmission ? Justifier.}
\tcor{
L'octet reçu $\base{11000101}{2}$ contient 4 bits valant 1. Le nombre de bits à 1 étant pair, la règle de parité est vérifiée : le récepteur ne détecte pas d'erreur simple.
}
\Question{Quelle est la limite de cette méthode de détection d'erreur ? Que se passe-t-il si deux bits sont altérés simultanément lors du transfert ?}
\tcor{
Si deux bits (ou plus généralement un nombre pair de bits) sont simultanément modifiés par le bruit lors de la transmission, la parité du nombre de bits à 1 reste inchangée. L'erreur n'est donc pas détectée par le récepteur. Le bit de parité ne permet de détecter que les erreurs portant sur un nombre impair de bits (et en particulier les erreurs isolées d'un unique bit).
}
\end{Exercise}

\begin{Exercise}[title={Annulation catastrophique}]\\
On s'intéresse au calcul de la fonction $f(x) = \sqrt{x+1} - \sqrt{x}$ pour de grandes valeurs de $x$.
On suppose qu'un système calcule avec une précision limitée à \textbf{4 chiffres significatifs} en base 10 (c'est-à-dire que chaque résultat intermédiaire est arrondi à 4 chiffres significatifs).
On souhaite évaluer $f(1000)$.
\Question{Sachant que $\sqrt{1001} \approx 31{,}63858$ et $\sqrt{1000} \approx 31{,}62277$, donner les représentations arrondies à 4 chiffres significatifs de ces deux nombres.}
\tcor{
Avec 4 chiffres significatifs :
$$\sqrt{1001} \approx 31{,}64 \qquad \text{et} \qquad \sqrt{1000} \approx 31{,}62$$
}
\Question{Effectuer la soustraction de ces deux valeurs arrondies. Combien de chiffres significatifs le résultat obtenu comporte-t-il ? Que constatez-vous ?}
\tcor{
On calcule la différence :
$$31{,}64 - 31{,}62 = 0{,}02 = 2 \times 10^{-2}$$
Le résultat ne comporte plus qu'\textbf{un seul chiffre significatif} ! Les trois autres ont été complètement perdus lors de la soustraction de deux grandeurs très proches (phénomène d'\textit{annulation catastrophique}).\\
La valeur exacte étant $f(1000) \approx 0{,}0158074$, l'erreur relative commise est énorme :
$$\left|\frac{0{,}02 - 0{,}01581}{0{,}01581}\right| \approx 26{,}5\,\%$$
}
\Question{En multipliant par la quantité conjuguée, donner une autre expression de $f(x)$.}
\tcor{
En multipliant et en divisant par $\sqrt{x+1} + \sqrt{x}$ :
$$f(x) = \frac{(\sqrt{x+1} - \sqrt{x})(\sqrt{x+1} + \sqrt{x})}{\sqrt{x+1} + \sqrt{x}} = \frac{(x+1) - x}{\sqrt{x+1} + \sqrt{x}} = \frac{1}{\sqrt{x+1} + \sqrt{x}}$$
}
\Question{Calculer à nouveau $f(1000)$ avec cette nouvelle formule en utilisant la même précision de 4 chiffres significatifs. Comparer avec la valeur exacte $f(1000) \approx 0{,}0158074$.}
\tcor{
Avec la nouvelle formule :\\
$\bullet$ Dénominateur : $31{,}64 + 31{,}62 = 63{,}26$ (addition de deux nombres positifs, aucun chiffre significatif n'est perdu).\\
$\bullet$ Inverse : $\dfrac{1}{63{,}26} \approx 0{,}0158077$, qui s'arrondit à 4 chiffres significatifs en $0{,}01581$.\\
Le résultat conserve bien ses 4 chiffres significatifs et l'erreur relative par rapport à la valeur exacte est inférieure à $0{,}02\,\%$.
}
\end{Exercise}
